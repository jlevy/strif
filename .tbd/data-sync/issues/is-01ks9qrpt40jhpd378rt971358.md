tests/test_hash.py only tests hashing a short string-written file. hash_file() reads in 8192-byte chunks (the while chunk := file.read(8192) loop) — the multi-chunk path is untested.

Add tests:
- Hash a binary file containing non-UTF8 bytes (e.g. os.urandom or bytes(range(256))) and compare to hashlib computed over the same bytes.
- Hash a file LARGER than the 8192 chunk size (e.g. 100 KB) to exercise the chunked loop; compare against hashlib.sha256 of the same content.
- Verify hash_file raises ValueError for an unsupported algorithm (the algorithm in hashlib.algorithms_available guard).
- Verify the Hash.hex / base36 / with_prefix outputs are consistent with a known value for a fixed input.

Use tmp_path fixture. Prefer sha256 for new assertions (and note sha1 is the current default for back-compat).

Acceptance criteria:
- Tests added to tests/test_hash.py (or a new file).
- Chunked path and binary path both exercised.
- lint + pytest green.
